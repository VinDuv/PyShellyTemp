The device identifier is a 6-character hexadecimal string that uniquely identifies the device. You can find it in the Web interface of the device, under Settings > Device info. If you do not know it, you can leave the field blank and it will be automatically filled when the new Shelly v1 H&T device sends a request for the first time.

Username and password used to login on the Shelly device’s web interface. These are used to query the device’s status and change its settings automatically. This can be left blank if no authentication is needed.
